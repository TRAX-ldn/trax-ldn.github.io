# TRAX-LDN

V0.1 storefront prototype for TRAX.

## Current prototype
- Editorial DIY landing page
- Product grid with category filters
- Placeholder products for tees, jeans, beanies, hoodies and accessories
- Product detail page with price revealed after opening a product
- Coming-soon product state
- Product data isolated in `assets/products.js` so products are easy to add/replace
- Shopify integration intentionally deferred until the store exists

This is a static prototype with no live checkout yet.
